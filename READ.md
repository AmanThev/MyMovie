## About the project
MyMovies is a web application developed with Symfony.

## Project goals
The main goal of this project is to learn the fundamentals of Symfony, Doctrine and Twig through a pratical application.

The project is developped progressively, with new features added as I learn new concepts.

## Technologies
* PHP
* Symfony
* Doctrine ORM
* MySQL
* Twig
* HTML/CSS

## What I learned
* Symfony
        * Creating and organizing a Symfony project
        * Creating Controllers
        * Defining Routes
        * Configuring a MySQL database
        * Creating Entities with Doctrine
        * Creating and loading Fixtures
        * Retrieving data with Doctrine
        * Using findAll() to retrieve all records
        * Using find() to retrieve a specific record by ID
        * Handling 404 errors when a movie does not exist

* Doctrine ORM
        * Creating entities
        * Mapping entities to database tables
        * Persisting data with persist()
        * Saving data with flush()
        * Retrieving data through repositories
        * Working with Doctrine Fixtures

* Twig
        * Creating and organizing templates
        * Passing data from a controller to a template
        * Displaying entity properties
        * Using for loops to display a list of movies
        * Creating a detailed movie page

## Current features
* Display the list of movies
* Display detailed information about a specific movie
* Retrieve movies from the database
* Handle non-existent movie pages with a 404 error
* Populate the database with sample movies using Fixtures
